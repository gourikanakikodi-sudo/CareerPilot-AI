# 🚀 CareerPilot AI

An AI-powered career guidance platform that helps students and professionals improve their resumes, prepare for interviews, practice coding, analyze ATS scores, identify skill gaps, and generate personalized learning roadmaps.

## ✨ Features

- 🔐 User Authentication (JWT)
- 📄 Resume Upload & Management
- 🤖 AI Resume Analysis
- 📊 ATS Score Analysis
- 🎯 Skill Gap Detection
- 🛣️ Personalized Learning Roadmap
- 💻 Coding Practice Module
- 🎤 AI Mock Interview
- 💼 Job Opportunities
- 📈 Dashboard & Analytics
- 👤 User Profile Management

## 🚀 Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
